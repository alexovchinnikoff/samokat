---

## 🔥 Главные риски (Impact Analysis)

1.  **Блокирующий баг в Chrome:** Невозможно оформить заказ в популярном браузере → остановка продаж.
2.  **Валидация телефона:** Принимается некорректный номер → курьер не может связаться с клиентом → срыв доставки (высокий бизнес-риск).
3.  **«Серая зона» ТЗ:** Неясно, кто валидирует поля (Frontend vs Backend) → риск пропуска дефектов.

---

## 🐛 Найденный баг (Ценность автотестов)

Автотест выявил несоответствие API:
> **Сценарий:** Отправка заказа с цветом `'red'`.
> **Факт:** Сервер игнорирует цвет и возвращает `'GREY'`.
> **Ценность:** Тест доказал наличие проблемы в бизнес-логике, которую легко пропустить вручную.
