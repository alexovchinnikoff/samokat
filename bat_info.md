🛠️ Как это работает (по шагам)
call .\venv\Scripts\activate.bat: Скрипт сам активирует твое окружение (venv). Тебе не нужно делать это вручную.
python -m pytest --alluredir=allure-results -v: Запускает тесты, собирает данные в папку allure-results и показывает подробный список тестов в окне.
allure serve allure-results: Это магия! Эта команда берет сырые данные из папки и запускает маленький веб-сервер. Автоматически откроется браузер с красивым интерактивным отчетом (графики, логи, шаги теста).
pause: В конце скрипт остановится и напишет «Нажмите любую клавишу...», чтобы окно не закрылось сразу, и ты успел прочитать итог.
⚠️ Важные условия для работы
Чтобы этот скрипт сработал, у тебя в корне проекта (samokat-root) должны быть: 1. Папка .venv (с активированным окружением). 2. Папка allure-results создастся сама при первом запуске. 3. Установленный Allure CLI. * Если у тебя нет программы allure (команда allure serve выдает ошибку), скрипт всё равно запустит тесты и сохранит данные в папку allure-results. * Ты сможешь открыть файлы внутри папки allure-results вручную или просто показать скриншот консоли.
#### Как проверить, есть ли Allure? В терминале напиши: powershell allure --version * Если версия есть (например, 2.25.0) — скрипт будет работать идеально, отчет откроется в браузере. * Если пишет "command not found" — тесты всё равно запустятся, но отчет в браузере не откроется. Это не страшно для портфолио, главное — что тесты работают.
